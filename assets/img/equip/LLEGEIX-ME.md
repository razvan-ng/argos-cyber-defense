# Fotografies de l'equip

Pugeu aquí les fotografies dels integrants amb **exactament** aquests noms
(en minúscules, sense accents ni espais):

| Integrant              | Nom del fitxer   |
|------------------------|------------------|
| Razvan Nastasa Ghitau  | `razvan.jpg`     |
| Lluc Sarrà Masdeu      | `lluc.jpg`       |
| Mouhammed Oualy        | `mouhammed.jpg`  |

- Format recomanat: **JPG quadrat**, d'uns 600 × 600 px (també s'accepten `.jpeg`, `.png` i `.webp`).
- Si la imatge no és quadrada, la web la retalla automàticament centrant-la una mica cap amunt (la cara).
- Mentre no hi hagi fotografia, la web mostra les inicials de cada integrant.
- GitHub Pages distingeix majúscules i minúscules: `Razvan.jpg` **no** funcionaria.
